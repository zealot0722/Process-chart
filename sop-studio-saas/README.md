# SOP Studio SaaS

這個專案提供兩種使用方式：

1. **一鍵開啟（免安裝）**
   - 直接開啟 `public/standalone.html`，即可在瀏覽器中預覽並編輯範例 SOP 樹狀流程。
   - 此版本使用 CDN 載入 React 與 Tailwind，離線即可使用，並提供搜尋、高亮、拖曳移動（含跨層級移動）、圖片放大，以及本機快速儲存等功能；僅分享/雲端功能被關閉。

2. **完整開發模式（需安裝依賴）**
   - 安裝依賴：`npm install`
   - 啟動開發伺服器：`npm run dev`
   - 將真實 Firebase 參數寫入 `.env` 後，雲端儲存/載入功能即可運作。

如需匯入/匯出 SOP，可在兩個版本中使用介面右上角的「匯入/匯出」按鈕。
